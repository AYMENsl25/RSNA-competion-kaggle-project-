1. Read `WRITEUP.md` and check the attribution and score distinctions.
2. Copy its Markdown into the write-up editor, if the competition currently

3. Attach the six PNG files from `assets/` using the editor's image control.
   Replace the six relative Markdown image targets with the attachment URLs
   returned by Kaggle. Local paths and a private GitHub repository are not
   publicly accessible image hosts.
4. Replace the relative technical-report link near the end with a URL accessible
   to the intended audience. The existing GitHub repository is private.
5. Preview tables, captions and images, then review author attribution before
   publishing. The availability of the editor and its exact image-upload behavior
   have not been verified by this package.

`writeup.html` embeds every image and works as a standalone local preview. It is
not a claim that Kaggle accepts an HTML-file import. No notebook or write-up has
been uploaded to Kaggle by generating this package.

The figures use aggregate results and schematics, with no patient MRI images.
Neither the images nor the text should be presented as evidence that the public
F0 architecture or its trained checkpoints were developed by this project.
