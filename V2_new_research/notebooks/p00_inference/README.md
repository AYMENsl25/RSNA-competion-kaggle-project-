# P00 epoch-3 offline inference

`infer.py` is generated by `python build.py` from the frozen `m00_data.py` and `m00_model.py` copies. The generated script embeds those exact sources and verifies their SHA-256 hashes before inference. It uses the official test CSV and DICOM series, the sample submission's exact column/UID order, deterministic 16 windows per plane, and chunked encoder evaluation preserving M00 max pooling. It fails on input or model errors instead of filling predictions.
