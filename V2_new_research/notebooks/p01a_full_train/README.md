# P01A full training (prepared, NOT run)

Backbone-only comparison against M00. The only experimental change is the encoder:
timm `coatnet_0_rw_224.sw_in1k` (ImageNet-1K pretrained, 768-d pooled features) instead of
random-init ResNet18 (512-d). Data path (`src/m00_data.py`), shared max over valid windows and
`M00.forward`, linear 12-logit head, masked BCE, split, labels, seed, epochs, batch sizes, LR,
AdamW, cosine schedule, AMP, time caps and selection rule are M00's, unchanged.
No finding attention.

Files
- `src/p01a_model.py` — `P01A(M00)`: `timm.create_model(name, pretrained=False, num_classes=0)`,
  official `model.safetensors` SHA256-checked, exactly `head.fc.weight [1000,768]` and
  `head.fc.bias [1000]` removed, remaining keys loaded `strict=True`. No network path exists.
- `train_template.py` — M00 template with only: P01A model construction, pretrained name/file/hash
  in `CONFIG`, `p01a_` output prefixes, source hashes, `timm`/`safetensors` versions in environment log.
  Audit with `diff --strip-trailing-cr ../m00_full_train/train_template.py train_template.py`.
- `train.py` — generated by `python src/research/build_standalone_notebooks.py`
  (`generate_p01a_full_train`); embeds m00_data, m00_model, p01a_model (its `from m00_model` line
  stripped; the builder asserts no `m00_` import remains).
- `tests/test_p01a.py` — synthetic CPU check: strict load from a fake state dict in the official layout
  (and rejection of wrong hash / missing key / extra key / missing classifier), no default-path download,
  forward `[2,12]`, backward with finite grads reaching the stem, padded windows (NaN) have no effect
  in eval and train mode. Optional real-file check via `P01A_WEIGHT_FILE=...`.

## Remaining gates

1. **CPU checks.** Builder and Python syntax compilation passed; `tests/test_p01a.py` needs an
   environment with torch/timm/safetensors and the Kaggle CPU preflight must pass.
2. **timm API.** Written against timm `maxxvit` (>=0.9 tag syntax) and checked at runtime:
   `pretrained_cfg["classifier"] == "head.fc"`, `num_features == 768`, strict key match. Not yet
   validated against an installed timm. Record the Kaggle image's `timm` version and confirm it creates
   `coatnet_0_rw_224.sw_in1k` offline (Internet off means no `pip install`; timm and safetensors
   must already be in the image).
3. **Offline weight dataset.** Private Kaggle dataset
   `aymenslimani/rsna-v2-official-coatnet0-imagenet1k` contains
   the official Hugging Face `timm/coatnet_0_rw_224.sw_in1k` checkpoint at the dataset root,
   SHA256 `efe01c8c139a4b0c360f508d10ae1217f7e3f3431fd85824438ed1110773366c`. Code only looks at
   `/kaggle/input/rsna-v2-official-coatnet0-imagenet1k/coatnet_0_rw_224_sw_in1k.safetensors` and
   `/kaggle/input/datasets/aymenslimani/rsna-v2-official-coatnet0-imagenet1k/coatnet_0_rw_224_sw_in1k.safetensors`.
   Run the test with
   `P01A_WEIGHT_FILE` pointing at the downloaded file before upload.
4. **Runtime.** CoAtNet-0 is ~4.2 GFLOPs/window vs ~1.8 for ResNet18, with attention in fp16 autocast.
   Run a matched short GPU pilot (as done for P00) and confirm the 3-epoch projection x1.2 fits
   `STOP_AT_S` (7.5 h) and peak memory fits; check AMP skip fraction stays <=1%. Do not launch the full
   run before this.
5. **Input-check of weights.** `--input-check` verifies data/labels/split only; the weight file is first
   hashed when `P01A()` is built after `prepare()`. A missing/mismatched file fails fast with
   `stop_reason: fatal:FileNotFoundError|ValueError`, not silently.
6. **Known, intended confound.** Inputs keep M00's [0,1] scaling (no ImageNet mean/std), same as P00,
   so the comparison isolates the backbone. 224x224 is required by CoAtNet's fixed attention size and
   matches `SIZE`.
7. **Push.** `kernel-metadata.json`: private, GPU on, Internet off, competition data, frozen split,
   public report labels, weight dataset. Not pushed.
